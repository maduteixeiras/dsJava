# dsJava

> Repositório criado com foco no estudo e aprendizado de Java, desde os fundamentos da linguagem.

## Java do 0

### Base da linguagem

Java é uma linguagem de programação:

* **Orientada a Objetos (POO):** segue o paradigma de Programação Orientada a Objetos, baseado em conceitos como classes, objetos, atributos e métodos.
* **Fortemente tipada:** toda variável possui um tipo definido, que não pode ser alterado após sua declaração.
* **Multiplataforma:** pode ser executada em diferentes sistemas operacionais e arquiteturas por meio da JVM (Java Virtual Machine).

### Como o Java funciona?

O código Java passa pelas seguintes etapas:

```
Código Java (.java)
        ↓
   Compilação
        ↓
Bytecode (.class)
        ↓
       JVM
        ↓
    Execução
```

O código-fonte Java é compilado para **bytecode**, que é executado pela JVM.

### JVM — Java Virtual Machine

A JVM (Java Virtual Machine) é o ambiente responsável por executar o bytecode Java.

Ela permite que o mesmo bytecode seja executado em diferentes sistemas operacionais, desde que exista uma JVM compatível.

### JDK — Java Development Kit

O JDK (Java Development Kit) é o conjunto de ferramentas utilizado para desenvolver aplicações Java.

Ele fornece recursos necessários para:

* Criar programas Java;
* Compilar o código-fonte;
* Gerar bytecode;
* Executar aplicações;
* Auxiliar no desenvolvimento e depuração.

### Resumo

```
JDK     → conjunto de ferramentas para desenvolver em Java
JVM     → ambiente responsável por executar o bytecode
Bytecode → código intermediário gerado após a compilação
```
